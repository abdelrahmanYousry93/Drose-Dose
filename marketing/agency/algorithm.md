# Algorithm discipline — applies to EVERY post and ad on every platform

The owner's standing instruction (15 Nov 2026): build each platform's algorithm in an organised way so it learns who
Dose's audience is. Every agent (production, growth reel, publisher, ads) follows this before producing or queueing.

## 1. One niche, always
- Every piece is about studying / Egyptian secondary (ثانوي) and prep (إعدادي) school life / understanding a lesson.
  No off-topic trends, memes or general motivation that a non-student would equally watch.
- First 2 seconds name the audience or their situation ("طالب ثانوي؟", "المدرس قال…", "ليلة الامتحان").
- Language: Egyptian colloquial Arabic only.

## 2. Fixed signal set per post
- Hashtags: always the 3 core tags `#ثانوية_عامة #تالتة_اعدادي #مذاكرة` + `#Dose`, plus at most 1–2 topical tags
  (subject or exam season). Never generic reach tags (#fyp, #explore, #viral).
- Same posting slots every day (growth reel 6 pm, feed post 8 pm Egypt time). Don't move slots without a reason
  written in the HQ log.
- Same visual identity (render.js brand colours, logo end-card) so repeat viewers are recognised as returning.

## 3. One goal per piece
- Growth reels → follow / save / send to a friend. Content posts → understand Dose. Booking posts → only when the site
  has bookable sessions. Never mix two calls to action in one piece.
- Every link carries its own `?src=` code (`fb-<key>`, `ig-bio`, `tt-bio`, `fb-boost-<key>`, `ig-boost-<key>`,
  `tt-boost-<key>`) so the funnel report can tell sources apart.

## 4. Ads
- Choose the objective by hand, never "تلقائي/Automatic": followers → Page promotion / profile visits; site → traffic;
  bookings → only after the pixel reports booking events.
- One objective per ad; don't edit a running ad's audience, budget or creative for at least 3–4 days (learning phase).
  To change the goal, propose stopping it and starting a new one.
- Boost only pieces that already did well organically (saves + shares), to audiences Egypt 18–55 on Meta
  (Meta does not allow under-18 targeting in boosts).
- Sequence: followers/video views first → retarget video viewers and site visitors → lookalike of bookers once
  there are 20–30 paid bookings. Never spend without the owner's approval of each ad.

## 5. Measure and feed back
- Weekly, the analyst ranks formats by saves, shares and follows (not likes) per platform and the next week leans
  toward the top 2 formats and drops the weakest.
- Pixel status: Meta Pixel and TikTok Pixel are NOT installed yet (owner task). Until they are, say so in any ad
  proposal — conversion-objective ads are not allowed before then.
